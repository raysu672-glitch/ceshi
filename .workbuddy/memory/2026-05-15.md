# 2026-05-15 工作日志

## 注册登录系统重构（v2）

### 核心变更
- **用户名+密码登录**：替代原来的姓名+密码，不需要手机号/邮箱
- **密码存 Supabase**：SHA-256 哈希存 students.password_hash，原文存 students.password_raw（管理员可查）
- **注册时一步绑定**：注册时验证密钥+身份确认+立即绑定，登录后无需再弹窗
- **会话管理**：session_token + session_expires，记住我7天/默认2小时
- **登录失败锁定**：5次失败锁定15分钟，模糊错误提示"账号或密码错误"

1. `supabase/full_schema.sql` — 重建全部表结构

   - access_keys 表新增：course_name, expires_at, batch_id
   - 删除 display_name 字段，用 real_name 代替
