### index.html 重构为登录/注册页

## 第四期实施：密钥激活系统

### 需求
- 学生注册时需要输入激活密钥，老师通过后台生成并分发密钥
- 支持预分配学生姓名 + 班级，跟踪密钥使用记录
- 支持 Supabase 云端 + localStorage 本地双模式（降级）

### supabase/schema.sql 更新
- 新增 `access_keys` 表：
  - `id` UUID, `key` TEXT UNIQUE, `student_name` 预分配姓名
  - `class_name` 预分配班级, `used_by` 实际使用者
  - `used_by_id` 使用者ID, `used_at` 使用时间
  - `is_active` BOOLEAN, `created_at` TIMESTAMPTZ
- 新增 `v_access_keys` 视图（方便管理端查询）
- RLS：允许匿名读取未使用的激活密钥（用于注册验证）

### tracker.js v4 升级
- 新增常量 `KEY_STORE = 'ielts_access_keys'`（localStorage 降级存储）
- 新增5个方法：
  - `generateKeys(count, studentName, className)` — 生成密钥，优先写 Supabase，降级写 localStorage
  - `validateKey(key, studentName)` — 注册时验证：检查有效性/是否已使用/预分配姓名是否匹配
  - `consumeKey(key, studentName, studentId)` — 注册成功后标记密钥已使用
  - `getKeys()` — 管理端获取所有密钥列表（含状态）
  - `revokeKey(key)` — 撤销密钥（软删除，is_active=false）
- 密钥格式：`XXXX-XXXX-XXXX`（12位大写字母+数字，排除易混淆字符 O/0/1/I）
- 更新 `return` 块导出5个新方法

### index.html 注册表单更新
- 新增「激活密钥」输入框（必填），placeholder 提示格式
- `handleRegister()` 改为 `async`，注册前调用 `tracker.validateKey(key, name)` 验证
- 验证通过后在 `localStorage` 设置密码 hash，再调用 `tracker.consumeKey()` 标记已使用
- Enter 键导航更新：`regPassword2` → `regKey`，`regKey` → 提交注册
- 错误提示细分：密钥无效/已被使用/已被撤销/预分配姓名不匹配

### admin/index.html 新增「🔑 密钥管理」Tab
- Tab 按钮插入在「设置」之后
- 统计卡片：总数 / 未使用 / 已使用 / 已撤销
- 生成区域：数量输入 + 预分配学生（可选）+ 预分配班级（可选下拉）+ 生成按钮
- 密钥列表表格：密钥 / 预分配学生 / 预分配班级 / 状态标签 / 使用者 / 使用时间 / 操作（复制+撤销）
- 状态标签样式：未使用（绿色）/ 已使用（灰色）/ 已撤销（红色）
- JS 函数：`loadKeys()` / `handleGenerateKeys()` / `handleRevokeKey()` / `copyToClipboard()`
- Tab 切换时自动调用 `loadKeys()` 刷新列表
- 新增 Toast 通知功能（含 CSS 样式）

### 使用流程
1. 老师进入后台 → 密钥管理 → 输入数量（可选填写预分配学生/班级）→ 生成
2. 老师将密钥发给对应学生
3. 学生注册时填写姓名+班级+密码+密钥
4. 系统验证密钥有效 → 注册成功 → 密钥标记为已使用
5. 老师可在后台查看密钥状态和使用者信息
